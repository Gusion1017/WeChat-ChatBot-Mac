# 微信 AI 聊天机器人（WeChat AI）v4.2.0

macOS 原生微信 AI 聊天机器人：接入 DeepSeek / OpenAI，支持拟人化回复、长期记忆、语音、识图与朋友圈。
修改微信客户端存在签名失效与账号风控风险，请先阅读风险说明并备份。

## 隐私说明

- 微信检测、运行状态、备份统计与诊断只在本机运行，不上传微信路径、账号或聊天内容。
- AI 通道 Key 仍只存 macOS Keychain；诊断/测试结果不写入 Key。
- 朋友圈与所有写操作仍默认关闭；时间线、评论、图片、捕获样本、sns key 缓存与记忆只存本机。
- 更新检查仅访问公开 GitHub API，无鉴权，不发送 Keychain、账号、wxid 或聊天内容。
- Release 二进制会 `strip`，不含编译机路径。

## 安装

1. 解压 zip，把 `WeChat AI.app` 拖到 `~/Applications` 或 `/Applications`。
2. 首次打开如被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」选择「仍要打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine "$HOME/Applications/WeChat AI.app"
   open "$HOME/Applications/WeChat AI.app"
   ```

3. App 以**菜单栏 agent** 运行并常驻菜单栏：**左键单击菜单栏图标开合状态面板**。
   启动时显示主窗口，关闭主窗口后退回仅菜单栏模式。
4. 首次向导：环境检查 → 检测微信 → 完全退出微信后备份并安装 Hook → 配置 AI → 启动。
   安装 Hook 需要 Xcode Command Line Tools；安装后需手动打开并登录微信。
5. 首次启用或每次微信重启后，在本机微信手动发一条消息捕获发送句柄；语音回复再发一条语音；朋友圈开启后
   打开一次朋友圈。捕获弹窗条目按已开启功能显示：文字常驻；语音 / 朋友圈 / 评论句柄在对应开关开启时出现
   （「评论或点赞一次」要求自动互动已开启、有互动对象且非演练）。

语音回复需要进入「机器人 → 语音」安装 Qwen3-TTS（约 4.7GB），并在「管理音色」导入参考音。

完整步骤见 [`docs/install.md`](../install.md)、[`docs/updates.md`](../updates.md)。

## 已知限制

- 回复**自己**的评论会被微信拒绝（`ret=-2`，服务端语义）；回复他人评论正常。
- 时间线以最近一次捕获的首屏请求为准；在朋友圈滚动较深后重新打开可能捕获到带旧游标的「首屏」，刷新会显示
  「最近动态 + 旧一页」，回到顶部再刷新/重新打开一次即可。
- 赞/取消赞与 objectop 写接口仍未打通（503）；userpage 主动发送未验证（保持 passive）。
- 好友回复仍为 Type=11 无正文，需 sns.db 只读补全。
- **微信 4.2.1.5 (270597) 未适配**：微信 Sparkle 自动更新可能把它装上，官方签名覆盖后 Gadget 注入消失、
  Hook 失效；App 会显示未适配并阻止启动。可用 `bash tools/manage_wechat.sh restore --backup-zip
  "$HOME/Library/Application Support/WeChatAI/backups/WeChat-4.2.1.3-270595-official.zip"` 回退后重新安装，
  并在微信设置里关闭自动更新。
- 语音发送、图片获取下载与群聊 @ 未在 4.2.1.3 / 4.2.0.17 逐一复测；语音发送的 4.2.0.5 真机链路沿用。
- 朋友圈时间线/评论依赖捕获样本与 sns key 缓存；微信重启后可能需重新打开朋友圈捕获。
- Qwen3-TTS 需额外安装约 4.7GB；CPU 模式极慢，通常超时后改发文字。
- 旧 `memories` / `memory_state` 表只读保留，不自动迁移；旧记忆需在记忆页手动导入。
- 仅适配上述 5 个微信版本；微信升级后可能失效，可用备份还原。

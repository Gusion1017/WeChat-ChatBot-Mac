## 升级

1. 完全退出微信。
2. 安装 Hook（会自动备份当前微信）：

   ```bash
   bash tools/manage_wechat.sh install
   ```

3. 重新构建 / 安装 App（默认目标已切到 4.2.1.9）：

   ```bash
   bash scripts/build_app.sh
   bash scripts/install_app.sh
   ```

4. 启动微信与机器人；首次启用 R3 发送前，在 Mac 微信里手动发一条消息捕获发送句柄；
   首次使用朋友圈前，手动打开一次朋友圈（读取）并手动发布 / 评论一次（捕获发布与 0xD5 评论模板）。
5. 安装脚本默认目标已切到 4.2.1.9；4.2.1.5 / 4.2.1.3 / 4.2.0.x 仍可通过 `KNOWN_VERSION_PAIRS` 安装。

## 回退

适配前的官方微信备份：

```
~/Library/Application Support/WeChatAI/backups/WeChat-4.2.1.9-270601-official.zip
```

```bash
# 完全退出微信后
bash tools/manage_wechat.sh restore \
  --backup-zip "$HOME/Library/Application Support/WeChatAI/backups/WeChat-4.2.1.9-270601-official.zip"
bash tools/manage_wechat.sh install
```

版本表回退：把 `hook/versions/4_2_1_9_mac.json` 的 `hookVerified` 改回 `"false"`（App 启动门禁会阻止
bridge），或直接恢复 `4_2_1_5_mac.json` 并重新 `install` 4.2.1.5。

## 已知限制

- 群聊 @、拍一拍、引用、图片 / 语音下载与语音发送未在 4.2.1.9 复测；`task_layout_mismatch` 安全闸保留。
- like / 取消赞 / objectop 写路径与 userpage 主动发送的既有未打通项不变。
- 仅支持 Apple Silicon / macOS 26+；修改微信仍有签名失效与账号风控风险，请保留官方备份。
- 发布包仍为 ad-hoc / 固定签名身份；安装用户请遵循 [`install.md`](../install.md) 的授权与回退说明。

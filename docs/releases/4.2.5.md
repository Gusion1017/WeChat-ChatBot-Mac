## 本版重点

- **微信 4.2.1.9 适配**：新增版本表并切为默认目标；58/58 地址键 `verified`，入站、R3 文本发送、通讯录已真机验证。
- **朋友圈完整读写**：4.2.1.9 的时间线主动刷新、发布、评论、回复与同步已验证，微信无崩溃。
- **适配工具**：`wxport` 强制保留全部 SNS 锚点；新版本朋友圈验收成为发布硬门槛。
- **签名与更新**：更新助手保留发布包签名；公开包默认 ad-hoc，不包含个人证书。
- **兼容性**：4.2.1.5 / 4.2.1.3 / 4.2.0.x 继续可用。

## 已知限制

- 公开包为 ad-hoc，应用内更新后可能需重新授权「完全磁盘访问」。
- 4.2.1.9 的群聊 @、拍一拍、引用、图片/语音入站与语音发送未全部复测。
- 4.2.1.9 的 `private` 发布在 macOS 侧可能回包成功但时间线不显示；自动发布仍为部分可见 + 单个对象。
- 仅支持 Apple Silicon、macOS 26+ 与上述 7 个微信版本；Qwen3-TTS 需另装约 4.7GB。

## 隐私

- 公开包不包含个人证书、私钥、本机路径或用户数据。
- 聊天、记忆、媒体、SNS 捕获与备份只存本机；更新检查只访问公开 GitHub API。

# 微信 AI 聊天机器人（WeChat AI）v4.2.1

macOS 原生微信 AI 聊天机器人：接入 DeepSeek / OpenAI，支持拟人化回复、长期记忆、语音、识图与朋友圈。

## 本版重点

- **逐功能修复**：会话设置回查、待回复消息槽、冷却/配额、定时任务持久化、失败提示与未来时间显示。
- **备份一致性**：导出前对账号库与记忆卡做 WAL checkpoint，staging 阶段真实拷贝数据库文件。
- **bridge / hook**：WS 心跳与读超时、请求体上限、入站串行队列、R3 媒体明确返回不支持。
- **稳定性与本地化**：语音服务失败态保留与自愈、更新页空态、英文文案与格式占位符校验。
- **兼容性**：4.1.x 移除；新增微信 4.2.1.5 适配（入站文本、R3 文本发送与通讯录已真机验证，朋友圈写链路强制只读）；4.2.1.9 未适配。

## 隐私说明

- 所有聊天、记忆、媒体、SNS 捕获与备份只存本机；调用 AI 时只发送所需上下文。
- 更新检查仅访问公开 GitHub API，无鉴权，不发送 Keychain、账号、wxid 或聊天内容。
- 数据备份只在本机由用户主动导出；仓库/Release 不包含用户数据。
- Release 二进制已 `strip`，不含编译机路径。

## 安装

1. 解压 zip，把 `WeChat AI.app` 拖到 `~/Applications` 或 `/Applications`。
2. 首次打开如被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」选择「仍要打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine "$HOME/Applications/WeChat AI.app"
   open "$HOME/Applications/WeChat AI.app"
   ```

3. 按首启向导安装 Hook 并配置 AI，然后手动打开并登录微信。
4. 首次启用或微信重启后，在微信里手动发一条消息（语音 / 朋友圈 / 自动互动按需额外捕获一次）。

完整步骤见 [`docs/install.md`](../install.md)、[`docs/updates.md`](../updates.md)。

## 已知限制

- 朋友圈赞 / 取消赞 / objectop 未打通；userpage 主动发送保持 passive；回复自己的评论会被微信拒绝。
- 微信 4.2.1.9 未适配；自动更新后可用 4.2.1.5 备份回退（见 [`4.2.1.5.md`](4.2.1.5.md)），并建议关闭微信自动更新。
- 语音发送、图片下载与群聊 @ 未在 4.2.1.3 / 4.2.0.17 全部复测。
- Qwen3-TTS 需另装约 4.7GB，CPU 模式极慢；旧 `memories` 表只读，不自动迁移。
- 仅支持 4.2.1.5 / 4.2.1.3 / 4.2.0.17 / 4.2.0.12 / 4.2.0.9 / 4.2.0.5。

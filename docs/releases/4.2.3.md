## 本版重点

- **更新不再重签**：应用内更新助手保留发布包签名，避免替换时用 ad-hoc 改写代码要求。
- **TCC 授权说明**：本机自建可用固定签名身份，反复重建保留「完全磁盘访问 / App 数据」授权。
- **公开包隐私**：Release 默认 ad-hoc，不读取个人 `.codesign-identity`，避免证书姓名 / Team ID 进入公开包。
- **4.2.1.5 适配延续**：入站、R3 文本发送、通讯录可用；朋友圈写链路仍强制只读。

## 已知限制

- 公开包为 ad-hoc，应用内更新后可能需要在「完全磁盘访问权限」中移除再重新添加。
- 微信 4.2.1.9 未适配；自动更新后需用 4.2.1.5 官方备份回退并关闭微信自动更新。
- 4.2.1.5 的朋友圈写链路未复测；赞/取消赞/objectop 与 userpage 主动发送限制不变。
- 语音发送、图片下载与群聊 @ 未在 4.2.1.5 全部复测；Qwen3-TTS 需另装约 4.7GB。

- 聊天、记忆、媒体、SNS 捕获与备份只存本机；更新检查只访问公开 GitHub API。

# 微信 AI 聊天机器人（WeChat AI）v4.2.4

macOS 原生微信 AI 聊天机器人：接入 DeepSeek / OpenAI，支持拟人化回复、长期记忆、语音、识图与朋友圈。
修改微信客户端存在签名失效与账号风控风险，请先阅读风险说明并备份。

## 本版重点

- **4.2.1.5 朋友圈完整读写**：时间线主动刷新、同步、发布、评论、回复已真机验证；移出只读名单。
- **适配工具硬门槛**：`wxport` 拒绝丢失 SNS 锚点，`REPORT.md` 增加朋友圈验收清单；新版本不再允许「聊天能用、朋友圈只读」直接发布。
- **签名与更新修复延续**：更新助手不重签；公开包默认 ad-hoc，避免个人证书进入包内。
- **兼容性**：4.2.1.5 / 4.2.1.3 / 4.2.0.x；4.2.1.9 未适配。

## 已知限制

- 公开包为 ad-hoc，应用内更新后可能需重新授权「完全磁盘访问」。
- 4.2.1.9 未适配；自动更新后需用 4.2.1.5 官方备份回退。
- 语音发送、图片下载与群聊 @ 未在 4.2.1.5 全部复测。
- 仅支持 Apple Silicon、macOS 26+ 与上述 6 个微信版本；Qwen3-TTS 需另装约 4.7GB。

## 隐私

- 公开包不包含个人证书、私钥、本机路径或用户数据。
- 聊天、记忆、媒体、SNS 捕获与备份只存本机；更新检查只访问公开 GitHub API。

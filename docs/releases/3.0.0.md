# 微信 AI 助手（WeChat AI）v3.0.0

macOS 原生微信 AI 助手：通过 Frida Gadget 注入本机官方微信，把消息桥接到 SwiftUI App，
由 DeepSeek / OpenAI 兼容模型生成回复。修改微信客户端存在账号风控与签名失效风险，
请先阅读风险说明并备份。

## 重要变更（3.0）

- **语音模型收敛为 Qwen3-TTS-1.7B（Apple MLX）**：移除 CosyVoice3 引擎、安装与 UI 选择器。
- 运行环境 `venv-qwen3tts`，模型 `Qwen3-TTS-12Hz-1.7B-Base-bf16`（约 4.2GB）+ 依赖约 0.5GB，
  合计约 4.7GB；安装/运行脚本不再有 `--engine`，不再 clone 仓库或安装 torch。
- 旧配置 `voiceEngine` 解码时忽略；旧 CosyVoice3 文件不再使用；设置页检测到残留时提供
  「清理旧版语音文件」（保留音色）。
- 服务契约升至 v2.0.0，`/health` 只报 `engine=qwen3tts` 与实际 `device`。
- **GPU / CPU 运行设备**：默认 GPU（MLX Metal，热态 RTF≈0.54–0.78）；CPU 为 MLX CPU 后端，
  实测 1.04s 音频约 644s（RTF≈619），仅建议排障/无 GPU 环境；App 180s 超时后改发文字。
- 模型未安装、服务未启动、旧版服务仍在或合成失败/超时时，本条改发文字，不做跨模型回退。

## 本版重点

- **参考音导入简化**：去掉扩展名白名单（可解码即可）；单段只需 ≥1 秒，超长按剩余总预算自动截取；
  合并 prompt 仍 ≤30 秒；导入/更换后默认自动转写参考文本（可关、可改）。
- 多条参考文本不再要求全填/全空；保存前自动补齐，仍缺失则按 cross-lingual 落盘。
- 新增 `ReferenceImportTests`（12 项），覆盖预算/截取、格式白名单移除、1 秒边界与混合文本。
- `devtools/cosyvoice/` 删除 CosyVoice3 专用的 patch/bench/perf 工具。
- 保留记忆 v2、多账号隔离、定时任务、菜单栏面板、图片识图、引用机器人等功能。

## 安装

1. 解压 zip，把 `WeChat AI.app` 拖到 `~/Applications` 或 `/Applications`。
2. 首次打开如被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」选择「仍要打开」，
   或执行：

   ```bash
   xattr -dr com.apple.quarantine "$HOME/Applications/WeChat AI.app"
   open "$HOME/Applications/WeChat AI.app"
   ```

3. App 以**菜单栏 agent** 运行并常驻菜单栏：**左键单击菜单栏图标开合状态面板**。
   启动时显示主窗口，此时 Dock 图标临时出现；**关闭主窗口后退回仅菜单栏模式**。
4. 首次向导：环境检查 → 检测微信 → 完全退出微信后备份并安装 Hook → 配置 AI → 启动。
   安装 Hook 需要 Xcode Command Line Tools；安装后需手动打开并登录微信。

语音回复需要进入「机器人 → 语音」安装 Qwen3-TTS（约 4.7GB），
并在「管理音色」导入自己的参考音；首次启用/微信重启后仍需手动发消息捕获发送句柄。

完整步骤与常见问题见仓库 [`docs/install.md`](../install.md)。

## 已知限制

- Qwen3-TTS 需额外安装约 4.7GB；CPU 模式极慢，通常超时后改发文字。
- 每条参考音 ≥1s，多条合计 ≤30s；超长自动截取开头。
- 旧 `memories` / `memory_state` 表只读保留，不自动迁移；旧记忆需在记忆页手动导入。
- R3 文本与语音发送都需要先捕获句柄：首次使用或微信重启后需手动发一条文字；语音回复另需发一条语音。
- 识图需要支持 `image_url` 的视觉模型；图片获取只处理实时入站图片。
- 4.2.0.12 的语音发送与图片获取下载未复测；群聊 @ 未单独复测。
- 仅适配 4.2.0.12 / 4.2.0.9 / 4.2.0.5 / 4.1.15.55 / 4.1.12.53；微信升级后可能失效，
  可用备份还原。

- App 为 ad-hoc 签名、未公证；只从本仓库或你信任的发布者获取二进制。
- **App/仓库不包含任何音色参考音频、`voices.json` 或私有音色生成脚本**；音色与参考文本只存本机。
- 记忆卡、聊天数据库、账号配置与媒体只存在本机，不进入仓库或 Release 包；
  Release 二进制已 `strip`，不含编译机路径。

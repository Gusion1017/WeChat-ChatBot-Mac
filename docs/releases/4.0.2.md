## 本版重点

- **修复朋友圈自动互动不回复评论**：原生评论 `comment_id` 是每条动态内的短 ID，不同动态会复用；
  旧账本键只包含评论 ID，导致一条动态处理过的短 ID 把其它动态的同 ID 评论全部拦掉。
- 去重键改为 `comment:<post_id>:<comment_id>`；候选去重、失败重试预算与 0 候选诊断均按动态隔离。
- 旧 `comment:<id>` 键不再匹配新键，30 天后自然过期；已回复的同帖评论仍由时间线中自己的回复兜底跳过。
- **修复一轮连续提交被 bridge 限流**：每轮最多提交 1 条互动，其余候选留给下一轮。
- 429 `sns_rate_limited` 只算本轮跳过，不写失败尝试、不消耗「3 次 / 10 分钟冷却」预算，下一轮直接重试。
- 0 候选日志新增「已处理评论 N」计数，用于区分「确实没有新内容」与「被已处理键拦掉」。
- 新增 5 条回归测试。

## 隐私说明

- 朋友圈读取/互动/发布仍默认关闭；互动对象只在本机从聊天白名单推导，不上传、不落库。
- 时间线、评论、图片、捕获样本、sns key 缓存与记忆只存本机；仓库/Release 不含真实动态或账号。
- 文档中的具体评论 ID、好友代称与真机时间已改为占位符。
- 更新检查仅访问公开 GitHub API，无鉴权，不发送 Keychain、账号、wxid 或聊天内容。
- Release 二进制已 `strip`，不含编译机路径。

## 安装

1. 解压 zip，把 `WeChat AI.app` 拖到 `~/Applications` 或 `/Applications`。
2. 首次打开如被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」选择「仍要打开」，
   或执行：

   ```bash
   xattr -dr com.apple.quarantine "$HOME/Applications/WeChat AI.app"
   open "$HOME/Applications/WeChat AI.app"
   ```

3. App 以**菜单栏 agent** 运行并常驻菜单栏：**左键单击菜单栏图标开合状态面板**。
   启动时显示主窗口，关闭主窗口后退回仅菜单栏模式。
4. 首次向导：环境检查 → 检测微信 → 完全退出微信后备份并安装 Hook → 配置 AI → 启动。
   安装 Hook 需要 Xcode Command Line Tools；安装后需手动打开并登录微信。
5. 首次启用或微信重启后，在本机微信手动发一条消息（语音回复再发一条语音；朋友圈开启后打开一次
   朋友圈并评论/点赞一次）捕获发送句柄/样本。

语音回复需要进入「机器人 → 语音」安装 Qwen3-TTS（约 4.7GB），并在「管理音色」导入参考音。

完整步骤见 [`docs/install.md`](../install.md)、[`docs/sns.md`](../sns.md)、
[`docs/updates.md`](../updates.md)。

## 已知限制

- 朋友圈 AI 自动互动运行期仍需长期真机观察；部分回复协议与 `ReferAction` 组合待确认。
- 朋友圈时间线/评论依赖捕获样本与 sns key 缓存；微信重启后可能需重新打开朋友圈捕获。
- 语音发送、图片获取下载与群聊 @ 未在 4.2.0.17 复测。
- Qwen3-TTS 需额外安装约 4.7GB；CPU 模式极慢，通常超时后改发文字。
- 旧 `memories` / `memory_state` 表只读保留，不自动迁移；旧记忆需在记忆页手动导入。
- 仅适配上述 6 个微信版本；微信升级后可能失效，可用备份还原。

## 安全与许可

- 仅在自己的设备与账号上使用；不要用于他人账号或绕过风控。
- 修改微信官方 App 会破坏签名，存在账号风险与数据丢失风险；安装前请自行备份聊天数据。
- App 为 ad-hoc 签名、未公证；只从本仓库或你信任的发布者获取二进制。
- **App/仓库不包含任何音色参考音频、`voices.json` 或私有音色生成脚本**；音色与参考文本只存本机。
- 项目遵循 GPL-3.0，源码与对应修改见仓库；分发二进制时请保留许可证与 `bridge/NOTICE`。

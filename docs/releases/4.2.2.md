## 本版重点

- **微信 4.2.1.5 适配**：新增版本表并切为默认目标；58/58 地址键 `verified`，入站、R3 文本发送、通讯录已真机验证。
- **Sparkle 升级防护**：安装/还原时清理已下载更新缓存；4.2.1.9 未适配，App 阻止 Hook 启动。
- **签名身份**：本机可用固定开发证书避免 TCC/Keychain 反复失效；本发布包为 ad-hoc。后续版本更新助手不再
  ad-hoc 重签；公开包默认 ad-hoc，本机自建可用固定签名身份（见 `docs/updates.md` §5.2.1）。
- **启动修复**：账号目录存在时自动创建 `temp/`，首次启动/微信更新后不再要求先打开图片。
- **Hook 适配工具**：新增 `tools/wxport` 与 [`hook-porting.md`](../hook-porting.md)，地址表仍只写入 `hook/versions/*.json`。

## 已知限制

- 4.2.1.5 的朋友圈写链路未复测，App 强制只读；赞/取消赞/objectop 与 userpage 主动发送限制不变。
- 微信 4.2.1.9 未适配；自动更新后需用 4.2.1.5 官方备份回退并关闭微信自动更新。
- 语音发送、图片下载与群聊 @ 未在 4.2.1.5 全部复测。
- 仅支持 Apple Silicon、macOS 26+ 与上述 6 个微信版本；Qwen3-TTS 需另装约 4.7GB。
- 本发布包是 ad-hoc 签名：应用内更新后若「完全磁盘访问」失效，需把 App 从权限列表移除再重新添加；
  后续稳定签名版本会保留该授权。

## 隐私

- 聊天、记忆、媒体、SNS 捕获与备份只存本机；更新检查只访问公开 GitHub API。
- 本发布包使用 ad-hoc 签名，不包含本机私钥或个人配置；后续版本默认沿用固定签名身份（证书是公开信息）。

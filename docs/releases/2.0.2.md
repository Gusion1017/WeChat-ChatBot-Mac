# 微信 AI 助手（WeChat AI）v2.0.2

macOS 原生微信 AI 助手：通过 Frida Gadget 注入本机官方微信，把消息桥接到 SwiftUI App，
由 DeepSeek / OpenAI 兼容模型生成回复。修改微信客户端存在账号风控与签名失效风险，
请先阅读风险说明并备份。

## 本版重点

- **移除主动聊天**：删除「机器人 → 主动」子栏目、`ProactiveChatPanel`、`ProactiveChatPlanner`、
  主动聊天设置/运行期状态与 60 秒轮询，以及对应测试与文档。
- 账号 `profile.json` 里的 `bot.proactive` 与账号库中的 `proactive.state` 不再读取，
  但保留一个版本，避免回滚时丢失配置。
- 历史主动消息继续作为普通出站消息保留在会话中。
- 机器人页子栏目恢复为 7 个：常规 / 触发 / 互动 / 名单 / 节奏 / 定时 / 语音。
- 定时任务、CosyVoice3（多条参考音）、记忆 v2、多账号隔离、图片识图、引用机器人、
  唤醒窗口等功能不变。

## 安装

1. 解压 zip，把 `WeChat AI.app` 拖到 `~/Applications` 或 `/Applications`。
2. 首次打开如被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」选择「仍要打开」，
   或执行：

   ```bash
   xattr -dr com.apple.quarantine "$HOME/Applications/WeChat AI.app"
   open "$HOME/Applications/WeChat AI.app"
   ```

3. App 以**菜单栏 agent** 运行并常驻菜单栏：**左键单击菜单栏图标开合状态面板**。
   启动时显示主窗口，此时 Dock 图标临时出现；**关闭主窗口后退回仅菜单栏模式**。
4. 首次向导（右上角可切换 **语言 / Language**）：环境检查 → 检测微信 → 完全退出微信后备份并
   安装 Hook → 配置 AI → 启动。安装 Hook 需要 Xcode Command Line Tools；向导可检测与引导安装。
   安装后需手动打开并登录微信；拒绝「App 数据」授权会导致图片/语音相关功能失败。

语音回复需要进入「机器人 → 语音」安装 CosyVoice3，并在「管理音色」导入自己的参考音；
首次启用/微信重启后仍需手动发一条文字 + 一条语音捕获发送句柄。

完整步骤与常见问题见仓库 [`docs/install.md`](../install.md)。

## 包含内容

- SwiftUI App（菜单栏、设置、会话、人格、记忆卡、定时任务、日志、语音、识图、CosyVoice 管理）
- Go OneBot bridge（`Contents/Resources/bridge/onebot`）与同步的 `script.js`
- Frida Gadget 17.8.0（`Contents/Resources/hook/gadget/FridaGadget.dylib`）

## 已知限制

- CosyVoice3 需额外安装约 8GB；CPU 推理偏慢，不是实时 TTS；未安装时语音回复直接改发文字。
- 每条参考音 5–30s，多条合计 ≤30s；多条参考文本必须同时填写或同时留空。
- 旧 `memories` / `memory_state` 表只读保留，不自动迁移；旧记忆需在记忆页手动导入。
- R3 仅支持文本；首次使用或微信重启后需手动发消息捕获发送句柄；语音另需发一条语音捕获。
- 识图需要支持 `image_url` 的视觉模型；图片获取只处理实时入站图片。
- 4.2.0.9 的语音发送、媒体下载、群聊 @ / 拍一拍本轮未复测。
- 仅适配 4.2.0.9 / 4.2.0.5 / 4.1.15.55 / 4.1.12.53；微信升级后可能失效，可用备份还原。

## 安全与许可

- 仅在自己的设备与账号上使用；不要用于他人账号或绕过风控。
- 修改微信官方 App 会破坏签名，存在账号风险与数据丢失风险；安装前请自行备份聊天数据。
- App 为 ad-hoc 签名、未公证；只从本仓库或你信任的发布者获取二进制。
- **App/仓库不包含任何音色参考音频、`voices.json` 或私有音色生成脚本**；音色与参考文本只存本机。
- 记忆卡、聊天数据库、账号配置与媒体只存在本机，不进入仓库或 Release 包；
  Release 二进制已 `strip`，不含编译机路径。
- 项目遵循 GPL-3.0，源码与对应修改见仓库；分发二进制时请保留许可证与 `bridge/NOTICE`。
